# 02. Article-Level Debate Map

## Purpose

This file supplies the missing layer between major books/commentaries and a full database export. It identifies article-level debate clusters, representative landmark articles or chapters, and the journals/indexes where each debate should be updated. It is not a final exhaustive bibliography; it is a scholarly map for harvesting, verifying, and expanding article-level literature.

## How to use this file

For each cluster:

1. Add the listed representative items to the bibliography after verifying exact metadata.
2. Search the named journals and indexes for the debate terms.
3. Add at least one recent state-of-the-question essay or review article.
4. Add non-English and critical/global scholarship when the debate has been dominated by English-language or Euro-American work.
5. Mark older but still influential works as `classic`, not automatically as `current`.

## 6. Article-level harvesting checklist

For every file in the repository, ask:

- Which five journals most often publish articles on this topic?
- Which two bibliographic indexes would a specialist search first?
- Which classic article or chapter created the debate?
- Which recent article changed the debate?
- Which review essay or handbook chapter summarizes the debate?
- Which non-English scholarship is indispensable?
- Which method has been overrepresented?
- Which method has been underrepresented?
- Which primary evidence controls the topic?
- Which ethical or provenance issues affect the evidence?
